How to set it up
  1. On GitHub, open Settings, then Developer settings, then Fine-grained tokens.
  2. Tap Generate new token. Name it "Fishing journal".
  3. Expiration: pick the longest. Repository access: Only select repositories, then fishing-journal.
  4. Permissions: Contents, set to Read and write.
  5. Generate it, copy it, and paste it below.
The key stays on this phone only. Anyone can read the journal. Only this key can change it.

River: Environment Agency, Marston on Dove gauge. Weather and flow forecast: Open-Meteo. Barbel rating: the Dove outlook rules.
